# Трекер расходов (MyБюджет)
Приложение на Python и Tkinter для учёта покупок и контроля статусов оплаты (`v1.0`).
## Функции
- Добавление покупки (номер, дата, название, стоимость в рублях).
- Проверка обязательных полей и числового формата цены.
- Поиск по названию или номеру и фильтр по статусу.
- Смена статуса по цепочке: `Запланировано` → `Оплачено` → `Проверено`.
- Удаление выбранной покупки с подтверждением (`Да / Нет`).
## Запуск
1. Установите Python 3 (библиотека `tkinter` уже встроена, внешние пакеты не нужны).
2. Убедитесь, что `images.png` лежит в одной папке с `app.py`.
3. Запустите команду:
   ```bash
   python app.py
   ```
   *(Данные хранятся в оперативной памяти и сбрасываются после закрытия окна).*
