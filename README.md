# Трекер расходов (MyБюджет)
Приложение на Python и Tkinter для учёта покупок и контроля статусов оплаты.
## Функции
- Добавление покупки (название, стоимость, дата).
- Поиск по названию или номеру и фильтр по статусу.
- Смена статуса: `Запланировано` → `Оплачено` → `Проверено`.
- Удаление покупки с подтверждением.
## Запуск
1. Установите Python 3 (библиотека `tkinter` уже встроена).
2. Убедитесь, что `images.png` лежит рядом с `app.py`.
3. Запустите команду:
   ```bash
   python app.py
   ```
   *(Данные хранятся в оперативной памяти и сбрасываются после закрытия окна).*
