# Трекер расходов
Простое настольное приложение на Python и Tkinter для подсчёта количества покупок и отображения последней добавленной записи.
## Возможности
- Ввод названия покупки и её стоимости в рублях.
- Подсчёт общего количества добавленных покупок.
- Отображение названия и цены последней добавленной покупки.
## Требования и запуск
- **Python 3** (библиотека `tkinter` входит в стандартную поставку, установка сторонних пакетов не требуется).
- Файл логотипа `images.png` должен находиться в той же папке, откуда запускается скрипт.
Запуск программы:
```bash
python app.py
```
